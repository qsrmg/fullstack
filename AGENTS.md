# AGENTS.md

## Cursor Cloud specific instructions

This is a beginner Python learning repository with standalone practice scripts. There are no frameworks, dependencies, build steps, or services.

### Environment
- **Runtime**: Python 3 (system `python3`)
- **Dependencies**: None — all scripts use only Python builtins
- **Lint**: No linter is configured; use `python3 -m py_compile <file>` for syntax checking
- **Tests**: No test framework; scripts are run directly with `python3 <file>`
- **Build**: No build step

### Running scripts
Each `.py` file is an independent script: `python3 conf.py`, `python3 qasir.py`, etc.

Note: Some scripts (`string.py`, `list.py`) contain intentional syntax/runtime errors as part of the learning exercises and will not execute cleanly.

### Scripts that run successfully
- `conf.py` — conditionals and operators
- `qasir.py` — comparison and arithmetic operators
- `loop.py` — for-loops and range()
- `dict.py` — all code commented out, runs with no output
